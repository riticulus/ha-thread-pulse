# Screenshots

Images of the tabs next to the map, from demo mode in dark mode (2× resolution), for posts, the wiki and the README.
Regenerate them (and the wiki images) with `python3 tools/screenshots.py` after layout changes.

| File | Shows |
|---|---|
| `network-1-overview.png` | Network panel – *Overview*: mesh health and the most important hints |
| `network-2-hints.png` | Network panel – *Hints*: all warnings and hints |
| `network-3-devices.png` | Network panel – *Devices*: device table, most messages, firmware |
| `network-4-links.png` | Network panel – *Links*: radio channels, weak links, routers the mesh depends on |
| `network-5-changes.png` | Network panel – *Changes*: change log |
| `battery-device-1-status.png` | Battery device (Front door) – *Status*: diagnosis, hints, values, battery, stability |
| `battery-device-2-link.png` | Battery device – *Connection*: live counters, Thread, signal trend |
| `battery-device-3-device.png` | Battery device – *Device*: device data, connected systems, identify |
| `router-1-status.png` | Router (Kitchen plug) – *Status* |
| `router-2-link.png` | Router – *Connection*: neighbours, best router link, if this router fails |
| `router-3-device.png` | Router – *Device*: firmware update, connected systems |
